# Learning demo

Open `tutorial.html` in a browser for the illustrated guide and generated audio preview. The screenshots and audio were produced by this fork.

The named Mac launchers and prepared native `.bsk` sessions belong to the local development workspace and are not bundled in this portable source package. On a fresh checkout, use `../scripts/launch.sh demo`, run the included builder once, and capture the two A clips as described in `../README.md`. The beat editor instructions demonstrate the prepared local session; a fresh checkout requires arranging the native sequencer viewport and bookmarks.

Development is paused as of 2026-10-24. See `../VALIDATION.md` for verified behavior and prototype limits.
